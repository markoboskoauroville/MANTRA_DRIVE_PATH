# addons.mozilla.org listing (Marko submits)

- Name: Drive Full Path
- Slug: drive-full-path
- Summary (250 max): Shows the full path of the open Google Drive folder in a thin bar at the top of the window, instead of Drive's three dots. Click the bar to copy the path.
- Description: Google Drive hides the middle of a deep folder's path behind "…". Drive Full Path writes the whole path in one small line at the top of the page, so you always know where you are. Click it to copy the path. It works only on drive.google.com, asks for no permissions, makes no network requests and stores nothing.
